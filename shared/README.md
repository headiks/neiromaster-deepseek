# shared/ — общий код сайта и приложения

Сайт (`frontend/`, React + Vite) и приложение (`mobile/`, Expo) показывают сотруднику
одни и те же данные одинаково. Всё, что не зависит от DOM или React Native, живёт здесь
и подключается в оба проекта как исходники TypeScript (без сборки и без npm-пакета):

| Файл | Что внутри |
|---|---|
| `types.ts` | Типы ответов API: пользователь, сообщения плана, вопросы, расписание, ответ ассистента |
| `api.ts` | Клиент API сотрудника (`createClient`): сайт — кука, приложение — Bearer-токен |
| `format.ts` | Даты и подписи: «Сегодня/Вчера», «Среда, 24 сентября», приветствие, инициалы |
| `progress.ts` | «День 3 из 30», текущий этап и «Дальше по плану»; итоги чек-листа/теста/опроса |
| `status.ts` | Статусы → тон бейджа и подпись (вопросы, документы, сотрудники, роли) |
| `tokens.ts`, `tokens.json` | Дизайн-токены Glass: палитры светлой/тёмной темы, отступы, шрифт |

Как подключено:

- **frontend** — алиас `@shared` в `vite.config.ts` и `tsconfig.json`.
- **mobile** — `metro.config.js` добавляет папку в `watchFolders`, импорт — относительный
  (`../../shared/...`). EAS Build берёт весь git-репозиторий, поэтому папка попадает в сборку.

Правило: здесь нельзя импортировать `react`, `react-native` и браузерные API — только
чистый TypeScript. Веб-стили (CSS-переменные) — в `frontend/src/styles/glass.css`,
значения совпадают с `tokens.json`.
